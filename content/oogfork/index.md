# OOG Fork Browser Extensions

OOG maintains a custom fork of the original [Refined Prun](https://github.com/refined-prun/refined-prun) project by Razenpok. The [OOG Refined Prun](https://github.com/jackinabox86/refined-prun).

# Installation

Stable builds may be installed from the Chrome or Firefox web stores:

* <a href="https://chromewebstore.google.com/detail/refined-prun-testing-fork/pcakabdnefjhjdgbiapchkejbkhdeebn" target="_blank" rel="noopener noreferrer">Install from the Chrome Web Store</a>
* <a href="https://storage.googleapis.com/oog-fork-gcs-bucket/refined-prun-latest.xpi" target="_blank" rel="noopener noreferrer">Download Firefox Extension (.xpi)</a>
* From Source at [GitHub](https://github.com/jackinabox86/refined-prun)
